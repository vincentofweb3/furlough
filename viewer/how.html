Mechanism

Reduce. Decide. Enforce.

Furlough splits the problem at the point where it matters: measurement and accounting are deterministic contract logic, while the only question sent to a model is one with three possible answers. The model's prose never crosses the consensus boundary, and the model's decision is never what restores the allowance.

The case lifecycle

A case is an allegation plus a URL. Filing one is permissionless and costs no fee on Studionet; the contract supplies the judgement process.

1

File

Anyone calls open_case with a claim, a case id and the URL of the agent's journal. There is no owner gate: a breaker only a trusting operator can trigger is not a breaker.

2

Reduce

The leader fetches the journal and collapses it to banded fields. Timestamps, exact counts, tool names, destinations and the journal's own id are discarded. Only stable shape survives.

3

Decide

Every validator re-fetches and re-reduces independently, then compares one enum. If the journal is unreachable the contract returns INSUFFICIENT_EVIDENCE itself and no model is consulted at all.

4

Enforce

A confirmed verdict sets expires_at. While the deadline is in the future the allowance reads as zero and draw() is refused. When it passes, the balance is available again with no transaction.

Stage 1 - what survives reduction

The decisive property is not "we summarise the journal". It is that two fetches of the same journal, with every volatile field different, must reduce to a byte-identical digest. A journal that merely grew must reduce identically too.

Volume is not misbehavior: a busy agent and a broken agent can both make sixty calls. What separates them is concentration. Ratios are banded rather than counts precisely because a 60-versus-61 difference would otherwise change the evidence while nothing meaningful changed.

Stage 2 - one enum, not a paragraph

Two models writing two rationales will never produce the same sentence. Comparing prose would stall every case forever, which makes the breaker decorative. So the contract compares exactly one field.

Compared

The verdict

One of CONFIRMED_MISBEHAVIOR, FALSE_REPORT or INSUFFICIENT_EVIDENCE. Anything outside the set is coerced to INSUFFICIENT_EVIDENCE; a missing field is not agreement.

Recorded, never compared

Rationale and digest

Both are stored so a reader months later can audit whether a verdict matches the evidence. Neither is an input to agreement, and a doctored digest cannot break a round.

A round therefore settles whenever the evidence is clear, and aborts when it is genuinely borderline. An aborted round cuts nothing: the agent keeps working, and the honest outcome of "we could not tell" is public.

Stage 3 - the clock is the unlock

There is no method that lifts a cut early. That is the product claim, and it is checkable rather than promised.

Restorationallowance_remaining() reads node time via window_closed(). At expires_at the balance returns by itself; no transaction exists to send.
Window boundset_default_cut_seconds is clamped to 1..3600 seconds, so no policy can arm a cut longer than an hour.
Policy changesChanging the default affects future cases only. It never rewrites an armed expires_at.
Re-pointingset_agent does not clear an open window. Swapping in a compliant agent is not an escape hatch.
OverlapA second confirmation composes by taking the later deadline. A false report never shortens a live cut.
Record-keepingreap_expired writes lifted_at for the public record. It is cosmetic: the allowance already returned before it could be called.

Custody and injection

Value safety

A cut suspends access, never destroys funds

deposited and drawn are written by exactly two methods, deposit and draw. No adjudication path touches either counter. refund is blocked while a cut is live, otherwise the operator could withdraw the balance and fund a fresh wallet.

Injection

The model can only say one of three words

The claim and every journal field are attacker-controlled. The verdict is validated against the enum; the claim is flattened so it cannot close its own delimiter; the measurements are labelled authoritative and placed first. The worst an injection can achieve is INSUFFICIENT_EVIDENCE - a deliberate fail-open choice, because failing closed would hand anyone a denial-of-service against any agent.

What this does not claim

Stated plainly, with the test that would fail if the claim broke.

Not audited

A testnet contribution. Do not use it with real value.

The journal is trusted infrastructure

Validators fetch it independently, but nothing proves the agent wrote it rather than someone posing as the agent. Signed digests are the next build.

Bands are hand-calibrated

Chosen against fixtures, plausible rather than validated against real agent traffic. Production wants distributions, which is governance as much as engineering.

The hermetic gate does not prove two real models agree

The test model is a deterministic stand-in keyed on the evidence. Real inter-model agreement needs a live network.
